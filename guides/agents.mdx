---
title: AI agents
description: Discover API operations from machine-readable references.
---

Give your agent the [OpenAPI specification](https://socialquery.dev/v1/openapi.json), [concise catalog](https://socialquery.dev/llms.txt), or [full endpoint index](https://socialquery.dev/llms-full.txt).

Use an HTTP tool with a server-side `x-api-key` header. The agent should inspect an operation's inputs, enforce a request budget, and stop on authentication, credit, or validation errors. Catalog presence does not guarantee live provider availability.

Create the account and API key through the dashboard. Automated account signup and an npm MCP package are not published as part of this beta.
