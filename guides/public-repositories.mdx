The public integration code is organized into four repositories under [ricciflow-api](https://github.com/ricciflow-api):

| Repository | What it contains |
| --- | --- |
| [socialquery-api-docs](https://github.com/ricciflow-api/socialquery-api-docs) | Documentation source and the public request specification |
| [socialquery-api-examples](https://github.com/ricciflow-api/socialquery-api-examples) | Tested request examples for Node.js, Python, and curl |
| [socialquery-agent-skills](https://github.com/ricciflow-api/socialquery-agent-skills) | The `socialquery-data` instruction package and its Python helper |
| [socialquery-mcp](https://github.com/ricciflow-api/socialquery-mcp) | MCP transports, client configurations, and protocol verification |

The MCP, skill, and example packages use the MIT license and connect to the hosted API. They do not distribute the main service implementation or its source-provider credentials. Calls are accounted against the requesting user’s SocialQuery balance.

Choose [the quickstart](/quickstart) for an HTTP integration or [agent setup](/guides/agents) for a tool client. Before relying on an operation, review [availability](/concepts/availability) and verify the required call.
