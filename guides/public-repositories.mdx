SocialQuery maintains four public integration repositories under [ricciflow-api](https://github.com/ricciflow-api):

| Repository | What it contains |
| --- | --- |
| [socialquery-api-docs](https://github.com/ricciflow-api/socialquery-api-docs) | This Mintlify documentation site and public OpenAPI contract |
| [socialquery-api-examples](https://github.com/ricciflow-api/socialquery-api-examples) | Runnable Node.js, Python, and curl examples with tests |
| [socialquery-agent-skills](https://github.com/ricciflow-api/socialquery-agent-skills) | Installable `socialquery-data` skill and Python helper |
| [socialquery-mcp](https://github.com/ricciflow-api/socialquery-mcp) | Working stdio MCP server, connection config, and protocol tests |

The MCP, skill, and examples repositories are MIT licensed. They call the hosted SocialQuery API; hosting code and provider credentials are not part of these packages. Data requests use your normal SocialQuery credit balance.

Start with [the quickstart](/quickstart) for direct API calls or [the agent guide](/guides/agents) for MCP and skill installation. Public catalog membership does not guarantee that a provider is live; see [availability](/concepts/availability).
