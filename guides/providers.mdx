---
title: Provider routing
description: Understand how a request reaches a supported source adapter.
---

Routing definitions are versioned with the application in TypeScript and JSON. Administrators can inspect readiness and request metrics in the dashboard; route and credential editing is outside that view.

An operation specifies a preferred provider followed by compatible alternatives. The server checks configuration and can try the next route after a retryable failure. Invalid input is returned directly to the caller. Requests for the same source may have different availability.

Your application authenticates to SocialQuery. Source-provider credentials are not part of the public request.
