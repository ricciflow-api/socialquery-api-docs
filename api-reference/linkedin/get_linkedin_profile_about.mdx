---
title: "LinkedIn Profile About"
openapi: "GET /linkedin/profile/about"
---

Public LinkedIn About summary, headline and displayed location. Unavailable text remains null. Member URNs, private contact details, account creation dates and verification metadata are unsupported.

A successful uncached call costs **5 credits**. Failed requests and cache hits cost zero.

Only observed public fields are returned. Missing data is not replaced with zero or inferred private metadata. Public visibility can change.
