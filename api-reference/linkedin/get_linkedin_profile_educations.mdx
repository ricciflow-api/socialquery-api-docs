---
title: "LinkedIn Profile Educations"
openapi: "GET /linkedin/profile/educations"
---

Visible public LinkedIn education entries with observed school, degree, field and year labels when available. Only page=1 is supported. Numeric school IDs and complete history are unavailable; school URLs may be null depending on the source.

A successful uncached call costs **5 credits**. Failed requests and cache hits cost zero.

Dates preserve source month/year labels, not invented timestamps. Unavailable values remain null. Public visibility can change. Sign-in placeholders and malformed responses are rejected, never treated as empty successful profiles. Unsupported filters return 422.
