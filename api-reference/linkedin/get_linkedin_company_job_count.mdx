---
title: "LinkedIn Company Job Count"
openapi: "GET /linkedin/company/job-count"
---

Retrieve the source-reported worldwide public job count for a numeric company_id. Returns company_id, count, and count_is_exact=null because the source does not distinguish exact counts from rounded or capped totals. This is a count, not a job listing. A successful live request costs 5 credits; cached responses and idempotent replays cost zero.

[Source documentation](https://docs.piloterr.com/linkedin-job-count).
