---
title: "LinkedIn Profile"
openapi: "GET /linkedin/profile"
---

Public LinkedIn profile identity, follower count and About summary. Headline, member ID, URN, connection count, verification and private status are unavailable when the public source omits them. Bio is not replaced by the About summary; read author.ext.summary.

A successful uncached call costs **5 credits**. Failed requests and cache hits cost zero.

This adapter uses public incognito data. Missing fields remain null. Unsupported filters return 422 rather than being silently ignored. Source windows and unavailable metadata differ from richer signed-in datasets.
