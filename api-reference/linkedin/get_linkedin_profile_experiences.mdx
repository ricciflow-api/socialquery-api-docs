---
title: "LinkedIn Profile Experiences"
openapi: "GET /linkedin/profile/experiences"
---

Visible public LinkedIn work experiences: role title, company, description and source date labels. Only page=1 is supported. This window is not guaranteed to be the complete career history. Numeric company IDs, employment types and role skills are unavailable. A current role is not proof of the profile’s selected top position.

A successful uncached call costs **5 credits**. Failed requests and cache hits cost zero.

Dates preserve source month/year labels, not invented timestamps. Unavailable values remain null. Public visibility can change. Sign-in placeholders and malformed responses are rejected, never treated as empty successful profiles. Unsupported filters return 422.
