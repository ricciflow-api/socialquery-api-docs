---
title: "Gumtree Search Suggestions"
openapi: "GET /gumtree/search/suggestions"
---

Get the current Gumtree UK search-box suggestions for a query. Each suggestion can include matching categories. Category-scoped ranking is unavailable; category_id returns 422. Highlight markup is omitted. No pagination.

One uncached successful request costs **5 SocialQuery credits**. Cache hits and failed requests cost zero. Initial provider verification shares a fixed 200-credit allowance; an exhausted allowance prevents further upstream calls. Unknown values remain null.
