---
title: "Gumtree Locations"
openapi: "GET /gumtree/locations"
---

Resolve a town or postcode prefix into a Gumtree UK autocomplete window. Query must contain 2–200 characters. location_type filters that fetched window and does not widen the search. Coordinates are null if unavailable. No pagination.

One uncached successful request costs **5 SocialQuery credits**. Cache hits and failed requests cost zero. Initial provider verification shares a fixed 200-credit allowance; an exhausted allowance prevents further upstream calls. Unknown values remain null.
