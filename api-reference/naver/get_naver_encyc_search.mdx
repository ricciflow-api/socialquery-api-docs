---
title: "Naver Encyclopedia Search"
openapi: "GET /naver/encyc/search"
---

Searches the anonymous [Naver Knowledge Encyclopedia](https://terms.naver.com/search?query=인공지능) index. This uses its public search UI and read-only continuation action; **no Naver Cloud credential is required**. The separate paid account setup remains on hold.

Results preserve native public IDs, titles, source links, plain-text excerpts, nullable thumbnails, categories, source names and content types. These are search excerpts, not full entry contents. The source mixes encyclopedia, video and magazine records. Global totals, publication timestamps and ranking scores are not supplied or invented; `total` is null.

Use `query`, `display` or `limit` (1–100; default 10), `start` (1–1000), and `sort=sim` (native relevance, default) or `sort=date` (native latest). Windows stop at source position 1,000. A returned `next_cursor` may be used alone and binds the query, size and sort for one hour. Explicit conflicts return an unbilled 422. The source rounds offsets to 30-row page boundaries; the adapter fetches aligned pages and slices the requested window, including short cursor pages and the final offset. Pagination advances over scanned positions, deduplicates within a window and rejects repeated full pages. Rankings are live and may shift; deduplicate by `id` across requests. Cursors are not snapshots or an exhaustive collection guarantee.

Each request verifies the public bootstrap query and exact continuation binding. It decodes data-only records, including length-prefixed UTF-8 excerpts, without executing scripts. Corrections, adult gates, changed source contracts and invalid provenance fail closed. Source links and thumbnails are returned without fetching entry bodies or downloading media. No account, cookie, user-profile, like or write API is called.

Fresh nonempty results cost **1 credit**. Empty results, errors, cache hits and successful idempotent replays cost zero. Use `X-Max-Credits: 1`. Each response is bounded to 2 MiB, the whole request to 45 seconds, and source reads to 20/minute. A request uses at most six anonymous reads (bootstrap plus five aligned native pages). There is no paid provider charge, vendor SLA or sustainable-capacity guarantee.
