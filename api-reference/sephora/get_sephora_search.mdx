title: "Sephora Search"
openapi: "GET /sephora/search"
---

Find Sephora US products by keyword. Prices preserve ranges in USD. Up to 60 rows per page and three pages. Keyword matching and supported sorting follow the source. Exact totals are unavailable; continuation uses observed look-ahead rows, not an estimated total.

A successful uncached call costs **5 credits**. Failed requests and cache hits cost zero. Empty or failed upstream Actor output is treated as an unavailable response, not a billed successful search.

Pagination re-fetches the source prefix; updates can shift products or reviews between calls. Keep parameters identical with a returned cursor. `window_truncated=true` on page 3 means more rows were observed but this adapter’s bounded window ends. A null cursor does not prove the full catalog or review archive was retrieved.

Unknown values remain null. Source execution uses a pinned Actor build, restricted permissions and a hard per-run cost cap. No login cookies, private profile fields or reviewer demographic traits are returned.
