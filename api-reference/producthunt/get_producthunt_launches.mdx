---
title: "Product Hunt Launches"
openapi: "GET /producthunt/launches"
---

Read the current public Product Hunt Atom feed, optionally narrowed by one of the verified topic slugs listed below. query and date filters apply to this feed window. Feed order is not vote ranking. Publication timestamps are post creation times, not launch days; votes, comments and maker handles remain null.

Each successful uncached request costs **1 credit**. The response has one current source window and no continuation cursor. Invalid requests and unavailable sources are refunded.

The feed usually contains 50 entries before local filtering. `since` and `until` accept ISO dates or timestamps with a timezone; date-only `until` includes the whole UTC day. Undated entries are retained. An unknown topic returns HTTP 404 rather than silently returning general launches. Product Hunt may change this public feed.

Supported topic slugs are taken from the public directory checked on 11 October 2026. This bounded list avoids Product Hunt silently returning unrelated general-feed entries for an unrecognized topic. A slug outside this list returns HTTP 404, even if Product Hunt has since added it.

`3d-modeling`, `3d-printer`, `a-b-testing`, `accessories`, `accounting`, `action-games`, `ad-blockers`, `adult-coloring-books`, `adventure-games`, `advertising`, `affiliate-marketing`, `alarms`, `alcohol`, `alexa-skills`, `alpha`, `amazon`, `analytics`, `android`, `animation`, `anonymous`, `artificial-intelligence`, `design-tools`, `developer-tools`, `email-marketing`, `social-media`, `web3`.
