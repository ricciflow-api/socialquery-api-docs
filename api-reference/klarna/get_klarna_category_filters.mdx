---
title: "Klarna Category Filters"
openapi: "GET /klarna/category/filters"
---

Returns native filter definitions grouped in source order for a product category (cl ID). An optional category_path_id must belong to that category’s regional hierarchy. Definitions do not include option values or product counts. Supports the 13 catalog regions. Empty content for a valid category has zero net charge; nonexistent categories return 404.

Use `category_id=cl94` for Headphones. The result retains the source numeric `id`, `groups[].name` and `groups[].filters[]`. Each filter contains `id`, `name`, `type`, `unit` and `description`; null values remain unknown. A filter may occur in several groups with different contextual descriptions. No option values or product counts are fabricated.

An optional `category_path_id`, such as `100003568-100014542` for US Headphone Accessories, must be an actual descendant of the requested category in that region. It maps to the native `af_100003568=100014542` query. Unknown or unrelated facets return 404. Use the category-children endpoint to find regional IDs. `returned_count` is the number of groups.

Regions: `usa` (default), `uk`, `germany`, `sweden`, `france`, `italy`, `spain`, `netherlands`, `austria`, `ireland`, `norway`, `finland` and `denmark`. Region changes the native language and available content. These are current public source snapshots, not promises of inventory or completeness.

A successful fresh request with content costs **1 SocialQuery credit**. Empty content for an existing category is fully refunded. Missing categories, invalid parameters, upstream failures, cached responses and successful idempotent replays have no net charge. Use `X-Max-Credits: 1` to cap the hold.

The anonymous source uses the shared 20-request/minute Klarna ceiling, a 25-second total timeout and a 2 MiB limit per response. Category validation may require one additional source request. Invalid source payloads fail explicitly; they are not converted into empty success or silently truncated.
