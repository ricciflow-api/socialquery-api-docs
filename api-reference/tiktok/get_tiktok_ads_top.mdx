title: "TikTok Top Ads"

Read TikTok Creative Center Top Ads. Supports country (default US), period (7, 30 or 180 days), keyword, industry, and for_you/impression/ctr/like sorting. limit defaults to 20 and accepts 1–100; the adapter reads at most five source pages. Ad-format, language, like-tier, date filters, and other sorting options return 422 without net charge. Source CTR and cost-index values remain in ext without assuming percentage or currency units. Media URLs can expire. next_cursor is null; increase limit for a larger first window. A successful live request costs 10 credits; cached responses and idempotent replays cost zero.

[Source documentation](https://docs.piloterr.com/tiktoktopads-search).
