---
title: "TikTok Post"
openapi: "GET /tiktok/post"
---

Accepts a canonical TikTok video `url`. Returns the matching post and its author, caption, thumbnail, duration, available engagement counts and publication time. Downloadable media URLs are not supplied by this source. `trim` accepts true or false; the normalized response omits raw provider fields in both cases.

<Note>The current EnsembleData source is a limited trial through October 18, 2026 UTC, with 50 shared provider units per rolling day. A missing or exhausted allowance returns an availability error without a net SocialQuery credit charge. Other configured sources may be tried when eligible; provider availability and response detail can differ. This is not a guarantee of continuous trial capacity.</Note>

Additional query parameters are rejected by this source. Cached results and idempotent replay use the standard zero-credit behavior. See the API response for credits used and request identity.
