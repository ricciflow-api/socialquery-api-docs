---
title: "Congressional Politicians Ranking"
openapi: "GET /us_congress_trades/stats/politicians"
---

Returns the requested top politicians by disclosed trade count from the [native Capitol Trades ranking](https://www.capitoltrades.com/politicians). `limit` is 1–50, default 20. The source's complete first page of up to 100 entries is checked before slicing. No offset, cursor or additional filters are accepted.

Each entry preserves the native member ID, full display name, party, two-letter state code and disclosure count. Names are not split by guessing, and abbreviated monetary labels are not converted into exact values.

Ranks are positions in descending source disclosure-count order. Ties retain source order and may move between requests. `total_indexed` counts indexed politicians, not trades. The source limits history to the past **three years**; these are current public-index counts, not lifetime trading activity or complete government filings. The ranking is read from native aggregates, not estimated from a partial sample of disclosures.

The adapter verifies the native count-sort option, page size/total, unique IDs, rendered identities and nonincreasing disclosure counts. It uses one existing Firecrawl basic-transport request, with a 42-second deadline, a 4 MiB decoded HTML limit and 20 shared ranking reads/minute. Streamed server HTML is parsed as data without executing scripts. No new provider account or key is required.

A fresh nonempty response costs **1 credit**. Empty results, errors, cache hits and successful idempotent replays cost zero. Use `X-Max-Credits: 1`. Existing approved Firecrawl free allowance only.
