---
title: Authentication
description: Keep request credentials with the application that executes calls.
---

Add the credential as `x-api-key` in the request headers. An absent, invalid, or expired credential receives HTTP 401; a key without the necessary operation access receives HTTP 403.

Save a newly issued key when it is displayed: the original value is shown only once, and SocialQuery retains its SHA-256 hash. Disable unused credentials in the dashboard. Store active values on the server and exclude them from frontend assets, URLs, screenshots, and public code.

Public catalog metadata can be read without a key. Signing into the dashboard creates a Supabase Auth session, which is distinct from an API request credential.
