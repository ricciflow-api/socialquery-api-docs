# SocialQuery API documentation

Public Mintlify documentation for https://socialquery.dev.

Run `npx mint validate` to validate the site and OpenAPI definition.

This repository contains the target API catalog. Endpoint availability is documented separately; catalog inclusion does not imply a live provider.

## Public integration repositories

- [MCP server](https://github.com/ricciflow-api/socialquery-mcp): runnable stdio server and connection configuration.
- [Agent skills](https://github.com/ricciflow-api/socialquery-agent-skills): installable `socialquery-data` skill and Python helper.
- [API examples](https://github.com/ricciflow-api/socialquery-api-examples): Node, Python, and curl examples.

Run `npm test` to check navigation and OpenAPI references locally.
