Use SocialQuery to request documented public records and inspect their outcomes. Resource data travels with common status, request identifiers, cache information, and credit accounting.

Begin with the exact request your feature needs. The catalog documents 646 operations across 68 sources, including contracts whose live access is still being enabled. Read [availability](/concepts/availability) and validate a small call before planning a larger workload.
