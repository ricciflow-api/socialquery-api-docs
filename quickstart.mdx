---
title: Quickstart
description: Prepare a backend credential and inspect one small response.
---

1. Open your account at [socialquery.dev](https://socialquery.dev/auth/login).
2. Issue a key from **Dashboard → API keys** and save the displayed value in secret storage.
3. Load that value through `SOCIALQUERY_API_KEY` in the environment that will execute the call.

```bash
curl --fail-with-body 'https://socialquery.dev/v1/hackernews/search?query=developer%20tools' \
  -H "x-api-key: $SOCIALQUERY_API_KEY"
```

Check both the HTTP outcome and `success` before reading `data`. Preserve `X-Request-Id` when diagnosing a problem. Provider failures return a structured error without a net credit charge; a currently unavailable operation responds with HTTP 503.

The website tester uses Cloudflare Turnstile to protect browser requests. Calls from your server authenticate with the API key instead.
